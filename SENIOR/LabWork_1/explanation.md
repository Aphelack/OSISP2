# LabWork 1. Поиск shell-скриптов и подсчет байтов

## Идея лабораторной

Лабораторная показывает базовую работу shell-скрипта с файловой системой: обход файлов, фильтрацию по имени, проверку содержимого файла и вычисление простой характеристики файла. Скрипт ищет файлы в текущем каталоге и ниже, выбирает только нужные по имени, проверяет, что первая строка похожа на заголовок bash-скрипта, записывает содержимое найденных скриптов в `result.txt` и считает сумму байтов.

Абстрактно работа состоит из четырех этапов:

1. Подготовить выходной файл.
2. Получить список всех файлов.
3. Для каждого файла решить, подходит ли он под условия пользователя.
4. Если файл подходит, обработать его содержимое.

## Как запускать

Запускать скрипт нужно из каталога `LabWork_1`, потому что поиск идет от текущей директории `.`:

```bash
cd LabWork_1
chmod +x scr.sh
./scr.sh -r '.*\.sh$'
```

Режим `-r` принимает регулярное выражение для имени файла:

```bash
./scr.sh -r 'nested|hello'ё
```

Режим `-l` принимает список точных имен:

```bash
./scr.sh -l hello.sh script.sh nested.sh
```

Результат с пронумерованным содержимым bash-файлов записывается в `result.txt`, а суммы байтов выводятся в терминал.

## Привязка к коду

В начале задаются основные переменные:

```bash
OUTFILE="result.txt"
HEADER="#!/bin/bash"
TOTAL_SUM=0
```

`OUTFILE` — файл, куда сохраняется найденное содержимое. `HEADER` — строка, по которой определяется bash-скрипт. `TOTAL_SUM` хранит накопленную сумму байтов.

Строка ниже очищает файл результата перед новым запуском:

```bash
> "$OUTFILE"
```

Список файлов собирается командой:

```bash
ALL_FILES=$(find . -type f)
```

Здесь `find . -type f` означает: начиная с текущей директории, найти все обычные файлы. Затем скрипт проходит по ним циклом:

```bash
for FILE in $ALL_FILES; do
    FILENAME=$(basename "$FILE")
    MATCH=false
```

`basename` убирает путь и оставляет только имя файла. Например, из `./testdir/hello.sh` получится `hello.sh`.

Фильтрация по регулярному выражению выполняется так:

```bash
if [[ "$1" == "-r" && "$FILENAME" =~ $2 ]]; then
    MATCH=true
```

Если первый аргумент `-r`, то второй аргумент воспринимается как регулярное выражение. Оператор `=~` проверяет, подходит ли имя файла под шаблон.

Фильтрация по списку имен устроена отдельным циклом:

```bash
elif [[ "$1" == "-l" ]]; then
    for ARG in "${@:2}"; do
        if [[ "$FILENAME" == "$ARG" ]]; then
            MATCH=true
            break
        fi
    done
fi
```

`"${@:2}"` означает "все аргументы, начиная со второго". Так скрипт сравнивает имя текущего файла со всеми именами, которые передал пользователь.

Если файл не подошел, он пропускается:

```bash
if [[ "$MATCH" == false ]]; then
    continue
fi
```

Проверка на bash-скрипт делается по первой строке:

```bash
FIRST_LINE=$(head -n 1 "$FILE" 2>/dev/null)
if [[ "$FIRST_LINE" == "$HEADER" ]]; then
    echo "Заголовок найден. Содержимое:" >> "$OUTFILE"
    nl -ba "$FILE" >> "$OUTFILE"
    echo "" >> "$OUTFILE"
fi
```

`head -n 1` читает первую строку файла. Если она равна `#!/bin/bash`, файл считается bash-скриптом. Команда `nl -ba` выводит файл с номерами всех строк.

Сумма байтов считается так:

```bash
FILE_SUM=$(od -An -tu1 "$FILE" | awk '{for(i=1;i<=NF;i++) s+=$i} END{print s+0}')
TOTAL_SUM=$((TOTAL_SUM + FILE_SUM))
```

`od -An -tu1` представляет файл как последовательность байтов в десятичном виде. `awk` проходит по всем числам и складывает их. Затем результат добавляется к общей сумме.

## На что обратить внимание

Скрипт использует `find`, `head`, `nl`, `od`, `awk`, поэтому он рассчитан на Unix-подобную среду. Также важно понимать, что `for FILE in $ALL_FILES` плохо работает с именами файлов, где есть пробелы. Для лабораторной это обычно допустимо, но в промышленном скрипте лучше использовать `find ... -print0` и чтение через `while`.

Еще одна особенность: строка вывода общей суммы находится внутри цикла, поэтому она печатается после обработки каждого подходящего файла. Если нужно вывести общую сумму только один раз, эту строку следует вынести после `done`.
