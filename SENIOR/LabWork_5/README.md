# Стресс-тестирование системы (LabWork_5)

Проект для стресс-тестирования системы с возможностью мониторинга использования ресурсов.

## Описание

Проект состоит из двух основных программ:

1. **stress_test** — утилита для создания нагрузки на систему (CPU, память, смешанная)
2. **monitor** — утилита для мониторинга системных ресурсов в реальном времени

## Структура проекта

```
LabWork_5/
├── Makefile          # Файл сборки
├── common.h          # Общие заголовки и структуры данных
├── stress_test.c     # Исходный код стресс-теста
├── monitor.c         # Исходный код монитора
├── test.sh           # Скрипт тестирования
└── README.md         # Документация
```

## Сборка

```bash
# Сборка всех целей
make all

# Сборка только stress_test
make stress_test

# Сборка только monitor
make monitor

# Очистка собранных файлов
make clean
```

### Параметры компиляции

- **Компилятор:** `gcc`
- **Стандарт:** `C11` с `_POSIX_C_SOURCE=200809L`
- **Флаги:** `-Wall -Wextra -O2`
- **Библиотеки:** `-pthread -lm`

## Использование

### stress_test

Программа создаёт нагрузку на систему с помощью многопоточных вычислений.

```bash
./stress_test [опции]
```

#### Параметры командной строки

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `-t`, `--threads` | Начальное количество потоков | 2 |
| `-m`, `--max` | Максимальное количество потоков | 20 |
| `-s`, `--step` | Шаг увеличения потоков | 2 |
| `-d`, `--delay` | Задержка между шагами (мс) | 500 |
| `-i`, `--iter` | Итераций на поток | 100000 |
| `-l`, `--load` | Тип нагрузки: `cpu`, `memory`, `mixed` | cpu |
| `-v`, `--verbose` | Подробный вывод | off |
| `-h`, `--help` | Показать справку | — |

#### Примеры использования

```bash
# Быстрый тест CPU (2→4 потока)
./stress_test -t 2 -m 4 -s 2 -i 5000 -d 200 -l cpu

# Полный тест (2→20 потоков)
./stress_test -t 2 -m 20 -s 2 -i 50000 -d 500 -l cpu

# Тест памяти
./stress_test -t 4 -m 8 -s 2 -i 1000 -d 300 -l memory

# Смешанная нагрузка
./stress_test -t 4 -m 12 -s 2 -i 5000 -d 300 -l mixed
```

#### Управление во время выполнения

| Сигнал | Действие |
|--------|----------|
| `Ctrl+C` / `SIGINT` | Остановка программы |
| `SIGTERM` | Остановка программы |
| `SIGUSR1` | Пауза/возобновление |

```bash
# Пауза/возобновление стресс-теста
kill -USR1 <PID>
```

### monitor

Утилита для мониторинга системных ресурсов в реальном времени.

```bash
./monitor [опции]
```

#### Параметры командной строки

| Опция | Описание | По умолчанию |
|-------|----------|--------------|
| `-i`, `--interval` | Интервал обновления (сек) | 1 |
| `-d`, `--duration` | Длительность мониторинга (сек) | 60 |
| `-s`, `--snapshot` | Сохранить снимок в файл | off |
| `-h`, `--help` | Показать справку | — |

#### Примеры использования

```bash
# Мониторинг в реальном времени (1 сек интервал, 60 сек)
./monitor -i 1 -d 60

# Быстрый мониторинг
./monitor -i 1 -d 30

# Сохранение снимка системы в файл
./monitor -i 1 -d 30 -s > system_snapshot.txt

# Запуск в фоновом режиме
./monitor -i 1 -d 120 &
```

#### Отслеживаемые метрики

- **CPU Usage** — загрузка процессора (%)
- **Memory Usage** — использование оперативной памяти (KB/MB/GB)
- **Swap Usage** — использование swap-раздела
- **Process Count** — количество процессов в системе
- **Uptime** — время работы системы
- **Топ процессов** — процессы по потреблению CPU и памяти

## Типы нагрузки

### CPU Load (`-l cpu`)
- Интенсивные математические вычисления (sin, cos, sqrt)
- Загружает процессор на максимальную производительность
- Минимальное использование памяти

### Memory Load (`-l memory`)
- Выделение и освобождение блоков памяти (1 KB)
- Запись и чтение данных
- Тестирование аллокатора памяти

### Mixed Load (`-l mixed`)
- Комбинация CPU и memory нагрузки
- Математические вычисления + выделение памяти (512 байт)

## Структуры данных (common.h)

### `thread_stats_t`
Статистика отдельного потока:
- `thread_id` — идентификатор потока
- `iterations` — количество итераций
- `result` — результат вычислений
- `elapsed_time` — время выполнения
- `is_active` — флаг активности

### `global_stats_t`
Глобальная статистика:
- `total_threads` — всего потоков
- `active_threads` — активных потоков
- `total_iterations` — всего итераций
- `total_time` — общее время работы
- `load_type` — тип нагрузки
- `threads[]` — массив статистик потоков

### `stress_params_t`
Параметры стресс-теста:
- `initial_threads` — начальное количество потоков
- `max_threads` — максимальное количество потоков
- `step_threads` — шаг увеличения
- `delay_ms` — задержка между шагами
- `iterations_per_thread` — итераций на поток
- `load_type` — тип нагрузки
- `verbose` — подробный вывод
- `monitor` — включить мониторинг

## Ограничения

- **MAX_THREADS:** 1024 (максимальное количество потоков)
- **MAX_ITERATIONS:** 10 000 000 (максимум итераций на поток)
- **DEFAULT_THREAD_DELAY_MS:** 100 мс

## Зависимости

- **GCC** с поддержкой C11
- **POSIX Threads** (pthread)
- **Math Library** (libm)
- **Linux** (для доступа к /proc/stat, /proc/meminfo)
