
# Лабораторная 3 — autocensor

## Идея лабораторной

Программа реализует простую цензуру входного текста по словарю запрещённых слов. Логика разделена между `autocensor.c` и модулем `censor.c`/`censor.h`. В корне есть `dict.txt` с примерами слов для фильтрации.

## Сборка

Собирается через `Makefile`:

```bash
cd Lab_3
make
```

В результате появится исполняемый файл `autocensor`.

## Запуск

Пример запуска (чтение из stdin, запись в файл):

```bash
./autocensor -d dict.txt -o test_output.txt < test_input.txt
```

В `Makefile` есть цель `test`, демонстрирующая простой пример: она создаёт `test_input.txt`, запускает программу и выводит `test_output.txt`.

## Структура файлов

- `autocensor.c` — точка входа и парсинг аргументов
- `censor.c`, `censor.h` — реализация фильтрации
- `dict.txt` — пример словаря
- `Makefile` — правила сборки и тест

## Примечания

- Код написан на C и компилируется с помощью `gcc`.
- Для теста и проверки используется цель `make test`.

## Привязка к коду (пошагово, для непрофессионала)

1) Точка входа — `autocensor.c`.
	- Программа запускается из командной строки. Она ожидает ключ `-d <файл>` — путь к файлу-словарю, опционально `-o <файл>` — файл для вывода и `-r <строка>` — текст, которым будут заменяться запрещённые слова (по умолчанию `[CENSORED]`). Для разбора аргументов используется стандартная библиотечная функция `getopt`.

2) Что такое словарь и как он читается.
	- Словарь — это текстовый файл (`dict.txt`), где каждое слово находится на отдельной строке. Функция `load_dict` в `censor.c` открывает этот файл, читает строки и запоминает слова в массиве. После завершения работы память, выделенная под слова, очищается вызовом `free_dict`.

3) Как программа обрабатывает текст.
	- Программа читает входной текст построчно (каждая строка — одна запись). Для каждой строки вызывается функция `censor_text`, которая возвращает новую строку, где все вхождения слов из словаря заменены на строку-замену.

4) Как именно происходит замена (упрощённо).
	- Для каждого слова из словаря функция ищет его в тексте (используется `strstr`). Но не каждое совпадение считается целым словом: проверяется, что перед совпадением и после него стоят не буквенно-цифровые символы или границы строки. Это нужно, чтобы, например, запрещённое слово `bad` не срабатывало внутри слова `badminton`.
	- Если совпадение найдено и считается отдельным словом, строка пересобирается: создаётся новый буфер, в него копируются части текста до совпадения, затем строка-замена, затем остаток текста после совпадения.

5) Память и безопасность.
	- Программа использует динамическую память (функции `malloc`/`strdup`). В местах, где возможна ошибка выделения памяти, код пытается корректно освободить уже выделенные ресурсы и завершить программу с сообщением об ошибке.

6) Ограничения и советы для тестирования.
	- Максимальное число слов в словаре ограничено (в этой реализации — 1000). Если слов будет больше, нужно увеличить константу или перейти на динамическую структуру.
	- По скорости: алгоритм прост и при большом словаре/длинном тексте может работать медленно, потому что для каждого слова выполняется поиск по всему тексту.
	- По регистру: текущая реализация чувствительна к регистру (`Bad` и `bad` — разные слова). Чтобы сделать поиск нечувствительным к регистру, можно привести и словарь, и вход к одному регистру (например, всё в нижний).
